# Security policy

## Supported versions

Security fixes are provided on a best-effort basis for the latest stable release of Household Tasks. Please update to that release before reporting an issue if practical. The minimum supported Home Assistant version is 2025.12.0. Older integration versions are not actively maintained.

## Reporting a vulnerability

Use the repository's [private vulnerability reporting page](https://github.com/thomtom24/HA-Household-Tasks/security/advisories/new) if private reporting is enabled. If the form is unavailable, open a public issue asking for a private security contact **without** describing the vulnerability or including a proof of concept.

Include the integration and Home Assistant versions, affected functionality, impact, reproduction steps and relevant redacted logs. Never send access tokens, credentials, private household task names, calendar contents or unredacted backups. Do not publicly disclose exploitable details before coordinating with the maintainer.

This project is maintained on a best-effort basis; no fixed response or resolution time is guaranteed. Ordinary non-security bug reports belong in GitHub Issues.
